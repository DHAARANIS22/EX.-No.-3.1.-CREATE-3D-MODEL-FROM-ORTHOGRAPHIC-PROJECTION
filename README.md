# EX. No.3.1. CREATE 3D MODEL FROM ORTHOGRAPHIC PROJECTION
## DATE:02-11-2026

## AIM:
To create a 3D model from given orthographic projection.

## REQUIREMENTS:
1. Autodesk fusion 360
2. Windows 10
3. 16 GB of RAM (integrated graphics recommend 1 GB or more)
4. 2.5 Mbps or faster download; 500 Kbps or faster upload 

## PROCEDURE:


1. Open Autodesk Fusion 360 and create a new design.

2. Select the **Create Sketch** option and choose the XY plane.
   <img width="442" height="653" alt="Screenshot 2026-11-16 010723" src="https://github.com/user-attachments/assets/68285d79-1f0c-4086-8284-fbdfdb65b23d" />


4. Use the **Line** and **Rectangle** tools to draw the main rectangular base profile according to the given dimensions.

   <img width="51" height="51" alt="Screenshot 2026-11-16 015231" src="https://github.com/user-attachments/assets/00b4634f-05b6-47a1-8507-7f19bf3d9627" />
   <img width="43" height="46" alt="Screenshot 2026-11-16 014652" src="https://github.com/user-attachments/assets/0180108b-53b9-414b-9040-e6a884098a9d" />



6. Use the **Arc** tool to create the semicircular portions at both ends of the base.
   <img width="192" height="82" alt="Screenshot 2026-11-16 020954" src="https://github.com/user-attachments/assets/4f0efef8-d768-42de-965d-58f086923c4b" />


8. Use the **Circle** tool to draw the three circular holes with diameters of 40 mm, 40 mm and 20 mm as shown in the drawing
   <img width="52" height="46" alt="Screenshot 2026-11-16 014634" src="https://github.com/user-attachments/assets/f5e36552-1498-4753-9fb1-2618feb62c2a" />


10. Apply the **Dimension (D)** tool to specify the required measurements, including 300 mm, 150 mm, 150 mm and 420 mm.
    <img width="70" height="57" alt="Screenshot 2026-11-16 014210" src="https://github.com/user-attachments/assets/1567a328-a795-4d51-83bb-c83a57587fc5" />


12. Click on **Finish Sketch** to complete the base profile.
    <img width="142" height="66" alt="Screenshot 2026-11-16 015045" src="https://github.com/user-attachments/assets/5f3fab48-00d6-4f92-a403-e0a43a8fa1b8" />


14. Select the **Extrude** tool and extrude the base profile to the required thickness of 30 mm.
    
<img width="305" height="341" alt="Screenshot 2026-11-16 021239" src="https://github.com/user-attachments/assets/97f5a2b0-c3ab-4246-b5af-667ab82b850d" />

16. Select the top face and create a new sketch for the raised central portion.

17. Use the **Line** and **Arc** tools to draw the required semicircular profile with a radius of 110 mm.

18. Apply the required dimensions, including 120 mm, 60 mm and 110 mm, according to the orthographic drawing.

19. Use the **Extrude** tool to create the raised central portion with the required height.

20. Use the **Hole** or **Extrude Cut** tool to create the required circular holes.

21. Apply the necessary geometric constraints and check the alignment of all features.

22. Inspect the completed 3D model using the Isometric View.

23. Finally, save the completed 3D model in Autodesk Fusion 360.
